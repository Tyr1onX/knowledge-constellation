# External Auditor — source-only notes

Case: `2026-08-18-sindresorhus-01`

The frozen sources support three different public contribution streams: Type-Fest as TypeScript type-utility stewardship, Ky as a focused Fetch-based HTTP client, and Awesome as large-scale open-source curation/governance.

Ky has the strongest behavior-level maintenance evidence in this snapshot: a direct authored/committed fix replaces timing-sensitive retry-test counts with stable behavioral invariants. This supports bounded troubleshooting/testing judgment, not generic distributed-systems mastery.

Awesome is specifically a trap for taxonomy inflation: curating links to many technologies does not make those technologies personal capability evidence. Type-Fest similarly supports type-level API work without proving TypeScript compiler internals.
