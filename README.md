# Knowledge Constellation｜知识星图

[English](README_EN.md)

> 看清自己现在会什么、做到什么程度，以及下一步最值得学什么。

### [打开交互预览 →](https://tyr1onx.github.io/knowledge-constellation/)

Knowledge Constellation 是一个 **Codex Skill**。

它会从你的 GitHub、项目、简历、学习记录、PR、笔记等真实资料中理解你做过和学过的东西，再把能够被证据支持的部分组织成一片属于你的知识星图。

它不是一次性生成：之后有新的资料，或发现哪里不准确，都可以继续用自然语言告诉 Codex，让这片星图重新校准并继续生长。

## 使用

把这个仓库地址发给 Codex，告诉它：**“帮我安装这个 Skill。”**

安装后，把关于你的资料交给 Codex，再告诉它：**“使用 Knowledge Constellation，为我生成知识星图。”** 剩下的交给 Codex。

生成以后也不用自己改文件。哪里不对、什么对你更重要、哪些部分其实由 AI 或协作者完成，直接告诉 Codex，它会根据你的补充重新理解并生成修正后的星图。

如果你有一个明确目标，也可以继续直接告诉 Codex，例如：**“我想找 Linux / C++ 后端实习。”** 它会把目标要求和你当前能被证据支持的能力分开建模，再告诉你哪些已经具备、哪些还无法确定，以及现在最值得推进的 1–3 件事。

## 星图

**星星**代表知识与经历，**星系**把相关内容聚在一起，**项目锚点**告诉你这些知识从哪里生长出来。

你可以拖动、缩放和探索它。随着视角靠近，更细的知识与关系会逐渐出现；随着学习、项目和新的真实资料加入，这片宇宙也可以继续生长。
