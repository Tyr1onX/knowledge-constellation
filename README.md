# Knowledge Constellation｜知识星图

[English](README_EN.md)

> 把关于你的资料交给 Codex，让它为你生成一片会生长、可探索的个人知识宇宙。

### [打开交互预览 →](https://tyr1onx.github.io/knowledge-constellation/)

Knowledge Constellation 是一个 **Codex Skill**。

它会从你的 GitHub、项目、简历、学习记录、PR、笔记等真实资料中理解你做过和学过的东西，再把它们组织成属于你的知识星图。

## 使用

把这个仓库地址发给 Codex，告诉它：**“帮我安装这个 Skill。”**

安装后，把关于你的资料交给 Codex，再告诉它：**“使用 Knowledge Constellation，为我生成知识星图。”** 剩下的交给 Codex。

生成后哪里不对，也直接告诉 Codex。它会把你的补充作为新的依据重新校准星图，而不是让你自己改 JSON 或节点。

## 星图

**星星**代表知识与经历，**星系**把相关内容聚在一起，**项目锚点**告诉你这些知识从哪里生长出来。

你可以拖动、缩放和探索它。随着视角靠近，更细的知识与关系会逐渐出现；随着新资料加入，这片宇宙也可以继续生长。
