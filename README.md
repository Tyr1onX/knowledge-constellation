# Knowledge Constellation｜知识星图

[English](README_EN.md)

> 把关于你的资料交给 Codex，让它为你生成一片属于自己的知识宇宙。

![Knowledge Constellation 效果预览](assets/preview.svg)

Knowledge Constellation 是一个 **Codex Skill**。

它不会让你自己填写“会什么”或给技能打分，而是从你真实留下的资料里理解你做过、学过和接触过的东西，再把它们组织成一张个人知识星图。

## 使用

1. 安装本仓库的 [`SKILL.md`](SKILL.md)。
2. 把关于你的资料交给 Codex，例如 GitHub、项目、简历、学习记录、PR、笔记或其他内容。
3. 告诉 Codex：**“使用 Knowledge Constellation，为我生成知识星图。”**

剩下的交给 Codex。

你不需要自己整理技术栈，不需要给能力打分，也不需要手动准备 JSON 或运行生成流程。

## 你会看到什么

- **星星**代表你的知识与经历；
- **星系**把相关内容自然聚在一起；
- **项目锚点**告诉你这些知识从哪里长出来；
- **放大探索**会逐渐显示更细的内容与关系。

星图会随着你提供的新资料继续生长。

> 效果图基于仓库现有 Tyr1onX 样本与当前 Renderer 视觉基线制作。
